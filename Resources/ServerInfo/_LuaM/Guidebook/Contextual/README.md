# Контекстная справка

Статьи этой папки открываются через «?» предмета или интерфейса и не входят в основное оглавление.

Для каждой статьи нужны запись в `docs/guidebook/GUIDEBOOK.md`, прототип `guideEntry` и привязка через `GuideHelp` либо вызывающий интерфейс. Порядок редактирования описан в `docs/guidebook/EDITING.md`.
